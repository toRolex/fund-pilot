# Design System

## Color Palette

| Token | Hex | Usage |
|-------|-----|-------|
| `bg-root` | `#0D0D11` | Page background |
| `bg-surface` | `#16161E` | Card / panel background |
| `accent` | `#60A5FA` (blue-400) | Primary interactive elements |
| `signal-buy` | `#34D399` (emerald-400) | Buy signal |
| `signal-sell` | `#FB923C` (orange-400) | Sell signal |
| `signal-hold` | `#FBBF24` (yellow-400) | Hold signal |

## Typography

- Font: Inter (system fallback: ui-sans-serif, system-ui, -apple-system)
- Scale: Tailwind default type scale

## Layout

- Single-page application with client-side routing
- Navigation sidebar persistent across routes
- Content area: responsive, max-width container
